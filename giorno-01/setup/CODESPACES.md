# Piano B · Codespaces

Per chi resta bloccato più di 30 minuti su un passo del setup: un ambiente online già pronto, nel browser, con VS Code dentro.

1. Entra su GitHub e apri il repository `corso-coding-arkemis`.
2. Pulsante verde **Code** → scheda **Codespaces** → **Create codespace on main**. Il primo avvio richiede 2–3 minuti.
3. Si apre VS Code nel browser con un terminale: lancia `python3 giorno-01/setup/check_setup.py`.
4. Lavora qui per il laboratorio di oggi. Stasera, con calma, sistema il setup sul tuo computer con la checklist: la slide e il canale domande restano aperti.

Da sapere: il piano gratuito dà 60 ore al mese per gli account personali; il Codespace si ferma da solo dopo 30 minuti di inattività e si riaccende da **Code → Codespaces**. A ogni riaccensione: `sudo service postgresql start`.
